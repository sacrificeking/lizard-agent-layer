# Project Context: Private Episodic

Curated context and a private, ignored episodic record are enabled.

- Read `.agent/memory/personal/PREFERENCES.md` for stable user preferences.
- Read `.agent/memory/semantic/DECISIONS.md` and `.agent/memory/semantic/LESSONS.md` when relevant.
- Use `.agent/memory/working/WORKSPACE.md` only for a concise handoff state.
- `.agent/memory/episodic/EPISODES.md` may contain bounded local task history only when the user requests it.
- Episodic content is ignored by Git but is still sensitive local data; minimize it and review it before export or deletion.
- Never persist credentials, customer records, regulated data, raw provider responses, or private source excerpts.
