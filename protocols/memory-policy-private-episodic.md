# Memory Policy: Private Episodic

The selected mode permits curated project context plus an ignored local episodic record.

- Keep stable preferences, accepted decisions, lessons, and handoff state concise and reviewable.
- Write episodic history only after explicit user direction and only to `.agent/memory/episodic/EPISODES.md`.
- Treat ignored episodic content as sensitive local data with an explicit retention and deletion decision.
- Never store credentials, customer records, regulated data, raw provider responses, or private source excerpts.
